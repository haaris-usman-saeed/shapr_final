# Audio attribution

All audio in the films is original and generated by code in this folder. No samples, loops, stock music or
third-party recordings are used, and no company's sonic logo is imitated.

| Element | Source | Licence |
|---|---|---|
| Music | `scripts/audio/score.py`: additive/FM keys, Karplus-Strong plucks, detuned pads, synthesised kick, shaker and rim, at 104 bpm. Original progressions (F major for "today", a D Dorian/minor variation for Shapr Flow) and an original three-note end signature (A–C–F). | Original, part of this repository |
| Sound effects | `sfx()` in the same file: short tonal sine/FM/noise sounds for circle draw and close, capture lift and land, panels, permission, merge, split, handoff, resume, logo | Original |
| Narration | Synthesised locally with **Kokoro v1.0** (open-weight TTS, Apache-2.0 model weights, via the MIT-licensed `kokoro-onnx` package), voice `af_heart`, speed 0.96. It is a stock synthetic voice, not a clone of any real person. | Apache-2.0 / MIT tools; output is ours |
| Human read (optional) | Drop files into `assets/audio/narration/human/` | Owned by whoever records it |

Pronunciation: the TTS reads "Shapr" as "shapper", so the script feeds it "Shaper".

Mix: music is ducked about 9 dB under narration; each film is normalised with two-pass `loudnorm` to
−16 LUFS integrated, −1.5 dBTP; 48 kHz stereo AAC in the MP4. Stems (music, effects, narration) are written to
`build/audio/<film>/`.
